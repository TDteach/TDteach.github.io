<p>严格精确匹配得到 42.1% 的补救成功率，数值提取得到 45.8%，经人工校准的 LLM 评审器得到 81.3%。严格精确匹配与评审器之间相差 39.2 个百分点；配对 McNemar 检验结果为 p&lt;10^-50，95% 自助法区间为 36.6–41.8 个百分点。论文将精确匹配视为基准实践的下界压力测试，而不是规范性的辅导指标。</p>
<p>作者还检验了这一差距是否只是单一评审器造成的。在两个按质量分层的标注子集中——100 段清晰对话和 100 段边界案例对话——四个 LLM 评审器与人工共识呈现较高一致性：清晰案例的 Cohen’s κ 为 0.786 至 0.905，边界案例为 0.740 至 0.872。人工标注者彼此之间的一致性为中等水平，而且这些子集并不能代表所有对话。</p>
<p>能力实验给出的结论更为审慎。在同类型错误诊断对照中，GPT-5-mini 在错误标签下测得的补救成功率为 80.8%，而使用金标准诊断时为 76.6%（p=0.078）；在所测试的格式下，这几乎不能证明正确的细粒度诊断带来了提升。包含六种条件的管线消融实验同样未发现提供管线信息能显著提升补救效果（p=0.263），但其等效性检验和功效分析仍允许较小效应存在。</p>
<p>可迁移的研究操作是：在比较评估器之前先固定生成的交互，再用人工标注校准自动评审器，而不是把某一个指标当作真值。适用边界同样重要：模拟学生的实验不能证明真实学生的学习效果；诊断结果仅适用于所测试的诊断呈现格式；经 55 名教育工作者验证的中学代数误解仅涵盖数学课程的一小部分。</p></div><p class="reading-reason">先读配对评分比较：它说明一项声称的辅导改进能否经得住评估器变化，再结合诊断消融实验理解能力方面的无显著结果。</p><details class="pn-sources"><summary>来源位置</summary><nav class="sources" aria-label="原文位置"><ul><li><a href="https://arxiv.org/abs/2610.31679v1" rel="noopener noreferrer">abstract; §4.4, Results, Table 3; paired-test rationale in Appendix J; §4.6, Results, Table 5; sampling and rubric in Appendix H; Appendix P, Table 13 and accompanying results; §4.5; §4.5, Results, Table 4; equivalence details in Appendix K; Ethical Considerations; Limitations, diagnosis-presentation format; Limitations, domain and taxonomy</a><span class="pn-source-id">arxiv:2610.31679v1</span></li></ul></nav></details></article>
<article class="pn-article" id="paper-2610.31833" aria-labelledby="heading-paper-2610.31833"><h2 id="heading-paper-2610.31833">潜在一致性审计通过上下文潜变量检验概率组合</h2><p class="paper-title"><a href="https://arxiv.org/abs/2610.31833v1" rel="noopener noreferrer">Latent Coherence: Do Frontier Language Models&#x27; Probability Judgments Obey the Law of Total Probability?</a></p><div class="pn-prose"><p>此前提供的相关一致性研究，在预测检查中考察了相关输入之间的关系——否定、释义、单调性和贝叶斯定理；本文针对的是另一种组合问题：对上下文推断出的潜在解释进行边缘化后，概率是否仍然一致。</p>
<p><strong>方法。</strong> 对每个条目，作者分别进行单轮调用，询问 <code>P(X)</code>、<code>P(z)</code> 和 <code>P(X|z)</code>，然后将直接概率与 <code>Σ_z P(z)P(X|z)</code> 进行比较。一个因果类别将同一思路用于 <code>P(y|do(x))</code> 和后门调整。每个查询都有精确的真实概率。对于选定子集，同一条目会用三种措辞提问，从而让作者能够区分持续存在的不一致与措辞变化带来的噪声。</p>
<p>在七个模型中，GPT-6.1 Sol 和 Claude Opus 5.5 的观测平均绝对残差最低，分别为 0.08 和 0.12 个对数几率。重复措辞分析基于 57 个条目中的 83 个潜变量同一性实例，检测到 Haiku、Gemini、DeepSeek，以及幅度较小的 GPT 存在持续不一致；作者报告称，这一部分主要体现为条目间的离散，而非共同的方向性偏移。在每个受评模型内部，残差越大，直接答案的错误也越大，Spearman 相关系数为 0.40 至 0.62。因此，论文将残差视为一种可能的无真值误差标记，同时指出这种关联有一部分是由机制本身产生的，并非对准确性的独立验证。</p>
<p>研究没有发现，在对同一条目进行三种措辞改写时，引出更多推理 token 会改善或损害一致性。在规模较小的因果子集中，普通后门调整检查几乎总能通过，而更显著的失败涉及对推断出的潜变量进行边缘化。使用模型自身的潜变量分解，也没有可靠地提高相对于直接作答的准确性；它是否有帮助取决于模型和条目。</p>
<p><strong>研究操作。</strong> 对于组合模型概率的系统，可分别引出直接判断和因子分解判断，计算残差，对选定条目进行受控改写后重复测试，并评估基于残差的分流能否在无标签的新条目上迁移。这既检验诊断能否经受措辞变化，也检验潜变量分解在实际操作中是否值得采用。</p>
<p>证据仍有限：结果只是对七个 API 模型的一个快照，而且关于持续不一致与噪声的分解依赖一个规模较小、区间较宽的重复条目子集。评估还只采用一种条件化表述。对于定性条目，与真值之间的误差部分反映了模型如何将文字表述转化为数字；而来源于 HoVer 的条目则依赖 LLM 生成并由 LLM 审核的分解。因此，残差是经基准评估的关联指标和审计信号，并非普遍的准确性保证。</p></div><p class="reading-reason">阅读本文，可借鉴对系统进行重复措辞残差审计的方法，同时明确该诊断与准确性之间的机制性耦合及其小样本局限。</p><details class="pn-sources"><summary>来源位置</summary><nav class="sources" aria-label="原文位置"><ul><li><a href="https://arxiv.org/abs/2610.31833v1" rel="noopener noreferrer">abstract</a><span class="pn-source-id">arxiv:2610.31833v1</span></li><li><a href="https://arxiv.org/abs/2306.09983v3" rel="noopener noreferrer">Section 6, Table 3 and Results, paragraph 1</a><span class="pn-source-id">arxiv:2306.09983v3</span></li></ul></nav></details></article>
<article class="pn-article" id="paper-2610.32531" aria-labelledby="heading-paper-2610.32531"><h2 id="heading-paper-2610.32531">NTBench 报告称，任务相关的错误与有害目标比受测固定目标具有更高攻击成功率</h2><p class="paper-title"><a href="https://arxiv.org/abs/2610.32531v1" rel="noopener noreferrer">On Task, Off Track: Benchmarking LLM and Agent Robustness to Near-Target Prompt Injection</a></p><div class="pn-prose"><p>固定目标的提示注入测试可能漏掉这样一种系统：它会拒绝明显偏离任务的请求，却接受一种注入式修改；这种修改保留了合法答案的大部分内容，却使答案变得错误或有害。NTBench 将这类提示注入称为近目标提示注入，并考察由参考答案引导的目标类别，能否揭示受测固定目标攻击未发现的失败。</p>
<p>与 LocalAlign 的一个重要区别在于用途：LocalAlign 将生成的近目标对抗样例用作偏好训练的负例；NTBench 则将由参考答案引导的错误和有害结果用作基准案例。对于每项任务，NTBench 先获取合法的参考结果，再用 LLM 分别生成错误结果和有害结果两条轨道上的目标—指令对。它结合基于 LLM 的检查和人工验证，以确认预期偏离是否成立；目标有效性与攻击成功率分开评估，并排除在没有注入时已经出现的偏离。</p>
<p>在 ASR@3 指标下——每个样本的攻击执行次数匹配为三次——在汇总语言任务评估中，每个受评模型在两条近目标轨道上的总体 ASR 都高于固定目标基线。错误目标的报告增幅为 9.3–35.8 个百分点，有害目标为 1.7–17.3 个百分点。对于 Meta-SecAlign-70B，汇总 ASR@3 从固定目标攻击下的 3.2% 升至错误目标下的 36.7%，以及有害目标下的 18.4%。</p>
<p>在 AgentDojo 和 AgentDyn 上，根据各自研究采用的成功判据，两条近目标轨道对每个受评模型也都超过了固定目标基线。</p>
<p>一项可立即复用的实验是：从合法参考答案生成目标类别，审查每个目标是否确实违反任务标准，并在固定攻击预算下，将诱发的偏离与无攻击运行进行比较。这样，评估关注点就从“某一个恶意目标是否奏效？”转向“注入能够诱发哪些任务违规？”</p>
<p>“近”在这里是构造提示，而不是强制规定的数值半径；因此，该基准不能说明结果如何随形式化的接近程度尺度变化，也不能说明生成的目标能否充分覆盖一个邻域。人工多数票审查发现，大多数抽样且保留的目标有效，但并非全部：在受审查的语言任务错误目标中，91.3% 被判定为有效；智能体错误目标中，这一比例为 98.0%。</p>
<p>对于工具调用目标，调用的工具和关键参数匹配，并不能证明下游效果；而智能体近目标与固定目标的比率使用了不同的成功判据。评估覆盖七个模型、十个语言数据集、AgentDojo 和 AgentDyn，且未增加运行时防御。应将结果视为关于这些受测配置的证据，而非普遍的鲁棒性结论。</p></div><p class="reading-reason">阅读本文，可了解改变攻击者的目标结果——而不只是注入措辞——如何在匹配的三次尝试预算下暴露失败。</p><details class="pn-sources"><summary>来源位置</summary><nav class="sources" aria-label="原文位置"><ul><li><a href="https://arxiv.org/abs/2610.32531v1" rel="noopener noreferrer">abstract; Section IV-B, S4.SS2.p1-p4; Section IV-C, S4.SS3.p1-p7; Section V-A, S5.SS1.p4-p5; Section V-B, S5.SS2.p2; Table II, S5.T2; Section V-B, S5.SS2.p2; Table II, S5.T2, Overall row; Section V-B, S5.SS2.p4; Table III, S5.T3; Section IV-B, S4.SS2.p3; Section VII, S7.p1; Section IV-C, S4.SS3.p6; Section VII, S7.p2; Section V-C, S5.SS3.p1-p2; Table IV, S5.T4; Section V-A, S5.SS1.p1-p2, p6</a><span class="pn-source-id">arxiv:2610.32531v1</span></li><li><a href="https://arxiv.org/abs/2605.01462v2" rel="noopener noreferrer">abstract</a><span class="pn-source-id">arxiv:2605.01462v2</span></li></ul></nav></details></article>
<article class="pn-article" id="paper-2610.33766" aria-labelledby="heading-paper-2610.33766"><h2 id="heading-paper-2610.33766">StateWise 训练 7–8B 语言模型追踪并遵守不断变化的约束，无需推理时账本</h2><p class="paper-title"><a href="https://arxiv.org/abs/2610.33766v1" rel="noopener noreferrer">StateWise: Teaching Language Models to Track and Obey Evolving Constraints in Multi-Turn Dialogue</a></p><div class="pn-prose"><h3>有何变化</h3>
<p>多轮约束处理有两种可分离的失败模式：有效规则可能不再得到遵守，而已撤销的规则仍可能被执行。ReBIND 已经通过子句级检查器，使撤销规则复发这一问题可执行地得到检验，并研究了基于账本的恢复。StateWise 改变了干预方式：在受测设置中，它训练一个 7–8B 的单一模型维护可修订的约束状态并据此作答，无需推理时账本。</p>
<p>StateWise 用有效约束和已撤销规则的墓碑标记来表示对话，编译出真实状态，并训练两项技能——从对话生成状态摘要，以及根据状态生成响应。随后，它在自身轨迹上进行自训练，只保留通过与编译状态精确往返检查的轮次。在偏好阶段，它构造由检查器标注的配对：拒绝执行已撤销规则的响应，选择通过往返检查的响应。</p>
<h3>证据</h3>
<p>仅在推理阶段进行的诊断并未修复问题：在论文对 Llama-3.1-8B 进行的 240 段对话评估中，让未经训练的模型写出自己的状态，会降低持续遵守率和对话成功率，同时增加复发。关键结果是，状态追踪与遵守行为并不一致：对于 Llama-3.1-8B，尽管状态追踪几乎完美，每种监督变体的复发率仍大致翻倍。在主要的留出评估中——Llama seed 1、六个未见过的约束族和 59 个 DPO 步骤——复发率从监督式自训练下的 0.246 降至 0.094，而对话成功率从主干模型的 0.290 升至 StateWise 的 0.370。</p>
<p>与监督式自训练相比，Stage III 的改进在第二个 Llama seed、Qwen2.5-7B-Instruct 和释义评估中再次出现；但相对于主干模型，在成功率与复发率两方面同时更优的结果，并非在每次复现中都通过检验。与仅包含有效约束的预言机式编译账本基线相比，在报告的比较中，StateWise 无需推理时脚手架就实现了更低的复发率；成功率方面的比较则取决于具体设置。</p>
<h3>边界与一项研究操作</h3>
<p>受测约束族属于格式层面的约束，且可通过程序检查；脚本化轨迹使用作者编写的释义来测试措辞变化，而语义约束和自然发生的对话尚未测试。复发指标排除了高偶然满足概率的约束族，因此低估了那些容易意外满足的约束所对应的复发率。在完全插值时，StateWise 的 IFEval prompt-strict 准确率比主干模型低 6.5 个百分点，在报告的英语 Multi-IF 评估中，每一轮的表现也都更低；插值降低了这一广度代价，但同时也让出了复发率方面的收益。</p>

<article class="pn-article" id="paper-2610.34073" aria-labelledby="heading-paper-2610.34073"><h2 id="heading-paper-2610.34073">智能体记忆的净价值，取决于逐查询与原始历史 RAG 的权衡</h2><p class="paper-title"><a href="https://arxiv.org/abs/2610.34073v1" rel="noopener noreferrer">Memory Tax: Dissecting the Net Value of Agent Memory</a></p><div class="pn-prose"><p>本文针对一个具体的评估局限：仅看单独的性能，无法看出记忆系统挽救的查询是否多于它损害的查询。在主要的对话记忆评估中，许多受测记忆系统的得分低于朴素 RAG，但结果会因系统、基准和主干模型而异。</p>
<p>本文在操作层面的改变，是将直接从原始历史记录中检索作为参照点，而不是把记忆系统的汇总得分视为充分依据。本文将记忆的净价值界定为两类查询之间的平衡：记忆能解决而 RAG 无法解决的查询，以及 RAG 能解决而记忆无法解决的查询。由于这一核算方式是相对于本文的朴素 RAG 参照定义的，收益和代价是依赖参照的度量，并非记忆本身不依赖参照的属性。</p>
<p>作者随后诊断代价可能从何而来。在一项抽样忠实度分析中，人工标注将 500 条原始对话轮次追溯到相应的记忆单元，并将其归类为无损失、部分损失、重大损失或不存在对应单元。作者的抽样人工标注发现，若干受测系统存在信息丢失或记忆单元缺失，为记忆构建环节导致记忆代价提供了证据。检索重放实验进一步考察保留下来的证据能否实际检索到：作者报告称，记忆检索往往需要比原始历史记录 RAG 更多的轮次才能找回证据，这表明存在与可获取性有关的代价。最后，跨主干模型实验表明，某些记忆机制带来的性能脆弱性可能超出朴素 RAG 所呈现的变化范围。</p>
<p>对于新的记忆系统，可迁移的操作是：以固定的原始历史记录 RAG 基线为参照，逐查询进行 2×2 审计。在依赖汇总得分之前，先报告仅记忆胜出和仅 RAG 胜出的查询；再对仅 RAG 胜出的查询抽样，并将其归类为构建损失、检索不可及或主干模型敏感性。由此形成的研究问题很具体：需要怎样的转换，才能让记忆带来的收益足以弥补其使证据更难保留或获取的代价？</p>
<p>这里的边界很重要。主要评估无法证明这些发现能推广到持续运行的多语言智能体，因为所用基准主要是静态、离线且为英语的。作者将基线选择描述为具有代表性，而非穷尽所有可能。有些评估使用分层子集，包括 GPT-5.6 Luna LongMemEval-s 的 100 个语料子集；论文也没有评估强于 GPT-5.6 Luna (low) 的模型。</p></div><p class="reading-reason">阅读本文，可了解一种具体的逐查询审计方法，用以区分记忆构建中的证据丢失、检索不可及和主干模型敏感性。</p><details class="pn-sources"><summary>来源位置</summary><nav class="sources" aria-label="原文位置"><ul><li><a href="https://arxiv.org/abs/2610.34073v1" rel="noopener noreferrer">abstract; Section 4.1, paragraph 2; Section 4.2, paragraph 2; Section 4.3, paragraph 2; Section 4.4, paragraph 2; Limitations</a><span class="pn-source-id">arxiv:2610.34073v1</span></li></ul></nav></details></article><footer class="pn-provenance">本期按 2026-11-01 的候选论文事后编制，核验日期为 2026-11-03。</footer></div>
